# Clover & Cha architecture

This is an editorial affiliate site built with TanStack Start and React 19. File routes live in `src/routes`; the route tree is generated by the framework. The root document provides social metadata from `src/data/site.ts`. Netlify's Vite adapter handles deployment.

`src/components/TeaSite.tsx` contains the shared layout, Clover mark, Home, filterable Shop, reusable ProductCard, disclosure, and editorial page content. `src/styles.css` defines the responsive visual system. Assets live in `public/img`, with hand-authored category SVG illustrations and one AI-generated hero still life. Serve the hero through Netlify Image CDN.

Use warm cream, sage, muted clay, and forest tones. Headings use Fraunces and body uses Nunito Sans, loaded through Google Fonts. Maintain keyboard focus, descriptive images, reduced-motion support, and mobile navigation.

The site deliberately has no commerce, enquiry submission, auth, or database. Product actions go to Amazon using sponsored/nofollow links. The initial products are sample ideas and untagged Amazon search links, not verified tested products. Do not claim otherwise. Keep the exact reader-supported disclosure near the top of every page containing product links and at body font size. The homepage category links are internal and need no affiliate disclosure. The contact email is explicitly an example and must be replaced before inviting real correspondence.

Product data is static editorial configuration, not persisted user state. Read category search parameters in an effect to preserve SSR hydration. Keep shared product presentation in ProductCard when reusing it elsewhere. Never add a cart, checkout, fabricated prices, ratings, or testimonials.

Local development: `pnpm install`, then `netlify dev --port 8889`. Build validation is handled by the deployment pipeline during automated editing runs.
